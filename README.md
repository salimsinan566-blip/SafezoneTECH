# SAFE ZONE - تطبيق وموقع إدارة مواعيد وعمليات أنظمة المراقبة الأمنية

نظام متكامل واحترافي مصمم خصيصاً لشركة وفنيي **SAFE ZONE** لتنظيم حجوزات تركيب وصيانة كاميرات المراقبة والأنظمة الأمنية، مع تقويم ذكي يحسب ساعات العمل ويلوّن الأيام حسب ضغط العمل بدقة، مع إمكانية التثبيت الفوري على هواتف أندرويد (APK / PWA) والعمل على أجهزة الكمبيوتر.

---

## المميزات الرئيسية المتوفرة في التطبيق

1. **التقويم الذكي وحساب ضغط العمل (Workload Heatmap)**:
   - **أخضر (Green)**: يوم فارغ متاح بالكامل (0% محجوز).
   - **أصفر (Yellow)**: شغل خفيف (حتى 40% من ساعات الدوام).
   - **برتقالي (Orange)**: شغل متوسط (41% إلى 75% من ساعات الدوام).
   - **أحمر (Red)**: يوم مزدحم / ممتلئ (أكثر من 75% أو محجوز بالكامل).
   - شريط تقدم ذكي لكل يوم يوضح الساعات المحجوزة مقابل ساعات الدوام المتاحة.

2. **قواعد تقدير مدة العمل وإعدادات الدوام (Flexible Rules Engine)**:
   - تخصيص ساعات الدوام اليومية (مثلاً من 08:00 صباحاً إلى 06:00 مساءً = 10 ساعات).
   - مصفوفة باقات الخدمات:
     - **نصب 4 كاميرات مراقبة**: يحجز 3 ساعات تلقائياً.
     - **نصب 8 كاميرات مراقبة**: يحجز 6 ساعات تلقائياً.
     - **نصب 16 كاميرا مراقبة**: يحجز 10 ساعات.
     - **صيانة وبرمجة DVR/NVR**: يحجز 1.5 ساعة.
     - إمكانية إضافة وحذف وتعديل الباقات وساعات حجزها بحرية تامة من شاشة الإعدادات.
   - إمكانية التعديل اليدوي على الساعات عند حجز أي موعد لحالات العمل الخاصة.
   - كشف التضارب الزمني التلقائي عند وجود موعد آخر في نفس التوقيت.

3. **بطاقات العمليات وإنجاز العمل الميداني**:
   - اسم العميل ورقم هاتفه مع أزرار اتصال سريع:
     - 📞 اتصال هاتفي مباشر (`tel:07xxxxxxxxx`).
     - 💬 محادثة واتساب فورية (`WhatsApp`).
     - 📍 عنوان العميل مع زر فتح مباشر في خرائط جوجل (`Google Maps`).
   - **نقطة التحقق البسيطة (Checkmark)**:
     - زر وخانة تدقيق واحدة بضغطة زر واحدة: **اكتمل ✓** أو **قيد التنفيذ ⏳**.

4. **الأمان والدخول**:
   - إمكانية تفعيل رمز حماية PIN سريع (4 أرقام) من الإعدادات لمنع العبث بالبيانات.
   - تصدير واستيراد النسخ الاحتياطية (JSON) لنقل المواعيد بين الأجهزة.

5. **التصميم والهوية**:
   - تصميم نهاري مشرق وفاتح باللونين **الأبيض والأصفر (White & Modern Amber)** لعلامة SAFE ZONE.
   - خط عربي عصري وواضح جداً تحت أشعة الشمس أثناء العمل الميداني.

## 🚀 النشر على Vercel والربط مع Supabase (سحابياً)

تم تجهيز المشروع بالكامل لدعم **Vercel** و **Supabase**:

### 1. إعداد قاعدة بيانات Supabase:
1. أنشئ مشروعاً جديداً في [Supabase](https://supabase.com).
2. افتح قائمة **SQL Editor** في لوحة تحكم Supabase.
3. انسخ محتويات الملف المجهز لك: [`supabase-schema.sql`](file:///c:/Users/user/Documents/antigravity/zealous-raman/supabase-schema.sql) والصقها ثم اضغط **Run**.
4. مبروك! تم إنشاء جداول المواعيد والإعدادات وتفعيل سياسات الأمان تلقائياً.

### 2. الرفع والنشر على Vercel:
1. ارفع الكود إلى مستودعك على **GitHub**.
2. في لوحة تحكم [Vercel](https://vercel.com)، اضغط **Add New > Project** واختر المستودع.
3. في قسم **Environment Variables**، أضف المتغيرين التاليين (تأخذهما من Supabase > Settings > API):
   - `VITE_SUPABASE_URL`: رابط مشروعك (مثال: `https://xxxx.supabase.co`)
   - `VITE_SUPABASE_ANON_KEY`: المفتاح العام `anon public`
4. اضغط **Deploy**. تم تجهيز ملف `vercel.json` مسبقاً لمنع أي مشاكل في مسارات المتصفح (SPA).

## طريقة تشغيل وبناء تطبيق الأندرويد (Android APK)

تم إعداد مشروع الأندرويد بالكامل عبر **Capacitor** داخل مجلد `android/`.

### 1. لفتح المشروع مباشرة في Android Studio:
```bash
npx cap open android
```
ثم اضغط على **Build > Build Bundle(s) / APK(s) > Build APK(s)** لاستخراج ملف الـ APK وتثبيته على أي هاتف.

### 2. لبناء الـ APK من موجه الأوامر (Terminal):
```bash
cd android
./gradlew assembleDebug
```
ستجد ملف الـ APK الناتج داخل:
`android/app/build/outputs/apk/debug/app-debug.apk`

### 3. لتحديث وتطبيق أي تعديلات مستقبلية على الأندرويد:
```bash
npm run build
npx cap sync android
```

## التثبيت الفوري كتطبيق هاتف (PWA) بدون Android Studio

التطبيق مجهز بملف `manifest.json` وأيقونة التطبيق:
1. عند فتح الموقع على متصفح هاتف الأندرويد (مثل Chrome).
2. اضغط على خيارات المتصفح (الثلاث نقاط) واختر **"إضافة إلى الشاشة الرئيسية" (Install App / Add to Home Screen)**.
3. سينزل التطبيق كأيقونة مستقلة لـ **SAFE ZONE** تعمل بشاشة كاملة مثل أي تطبيق أندرويد مثبت.
